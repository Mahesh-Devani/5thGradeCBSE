## 🚀 Getting Started

### View Locally
Simply open `index.html` in any web browser — no installation or server required:
```
open index.html
```

### Host on GitHub Pages
1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch** → `main` / `root`
4. Your site will be live at `https://YOUR_USERNAME.github.io/5thGradeCBSE/`

## 🎮 Features

- **📖 Learn Mode** — Interactive exploration with labels, notes, and textbook info
- **❓ Quiz Mode** — Test knowledge by finding regions on the map
- **⏱️ Timed Challenges** — Speed drills with countdown timers
- **🏆 Star Badges** — Earn ⭐⭐⭐ for perfection (with confetti! 🎉)
- **🖨️ Printable Worksheets** — Generate blank outlines and labeled references for homework
- **📱 Responsive** — Works on desktops, tablets, and phones
- **🌙 Dark Theme** — Premium glassmorphic design with animated backgrounds
