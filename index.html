🔒 Privacy, Keys & Device Safety
  • Audio & Voice: Speech recognition processes audio via the browser. No audio recordings are saved or stored.
  • Cloud AI Data: Only question text and transcribed answers are sent to the chosen AI provider. Off & Local modes send zero data to AI clouds.
  • Key Storage: API keys stay exclusively in this browser's local storage. They are never synced to Google Drive or included in backup file exports.
  • Security Warning: Anyone with access to this browser profile can read stored keys. Please use an API key with a low spending limit.
  • Device-Level Setting: Engine choice and keys apply to this browser/device, not per child profile.
